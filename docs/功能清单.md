## 二、视觉设计语言与核心 Token 规范

v0.2.0 全面采用**「纯净留白 · 暖琥珀金点缀」**视觉系统（参考 `.design_ref/ai_app.html` 与 `.design_ref/pc.html`），确保移动端与 PC 桌面端在色彩、排印、圆角与图标层面高度一致。

### 2.1 核心色彩 Token
| 语义角色 | Hex 色值 | 衍生浅底 / 悬停色值 | 适用场景 |
| :--- | :--- | :--- | :--- |
| **品牌主色（暖琥珀金）** | `#DE8A1E` | Hover `#C67612` / 浅底 `#FFF6E8`、`#FFF3DC` | 品牌重点强调、激活 Tab 图标、主行动按钮、渐变 FAB（APP `145deg #F0A336 -> #D98014` / PC `135deg #ECA034 -> #DA8316`） |
| **支出强调色（红陶）** | `#D6553E` | 浅底 `#FDF0EE`、`#FDF1EE`；日历 3 档热力色 `#FDF0EE` / `#FADCD6` / `#F5C4BC` | 支出金额、负向趋势、热力日历支出强弱格、删除/警戒状态 |

### 2.2 字体排印与组件圆角
* **字体家族**：`'Inter', -apple-system, BlinkMacSystemFont, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif`。
* **等宽数字排版**：所有金额、预算水位、日期、统计数值与 Token 计数强制启用 `tabular-nums`（`font-variant-numeric: tabular-nums`），确保多行列表与表格纵向对齐不抖动。
* **圆角体系**：
  * APP 端主卡片 `.app-card`：`22px` 圆角；底部 4 Tab 胶囊悬浮 Dock（`.glass-dock`）搭配毛玻璃模糊 `backdrop-filter: blur(26px) saturate(180%)`；
  * PC 端主卡片 `.pc-card`：`20px` 圆角；居中弹窗 `26px` 圆角；分栏认证容器 `28px` 圆角。

### 2.3 双层双色 SVG 图标与 3D 小猫头像库
* **30 款双层双色几何 SVG 图标系统**：摒弃杂乱卡通贴纸风，采用统一线性几何路径 + 主题浅底色块的双层双色矢量图标（如 `bowl`、`coffee`、`breakfast`、`bento`、`fruit`、`dining`、`bag`、`cart`、`shirt`、`laptop`、`sparkles`、`train`、`car`、`fuel`、`plane`、`home`、`bolt`、`wifi`、`wrench`、`film`、`gamepad`、`dumbbell`、`compass`、`medkit`、`book`、`paw`、`gift`、`wallet`、`star`、`trend`、`refund`、`tag` 等 30+ 图标覆盖消费、交通、居家、娱乐、宠物、金融与收入全场景），支持在分类管理中自由选配图标与专属色。
* **6 款 3D 毛绒小猫头像库 & Canvas 圆形裁剪器**：
  * 内置 6 款预设 3D 毛绒小猫头像：`小银灰`（`cat_grey`）、`大橘宝`（`cat_orange`）、`小三花`（`cat_calico`）、`小布偶`（`cat_ragdoll`）、`奶牛猫`（`cat_tuxedo`）、`招财黑猫`（`cat_black`），用户注册时自动随机分配，也可随时在头像面板切换；
  * 内置 **交互式 Canvas 圆形裁剪器**：支持从本地上传任意图片，通过手势/鼠标拖拽平移、滑动条缩放（`1.0x ~ 3.0x`），在圆形遮罩内实时预览并导出高清头像持久化至后端 `/api/v1/avatars/:filename`。

## 三、混合认证架构与账号体系

### 3.1 双模式无缝认证
1. **UGOS Pro 网关免登（NAS 内置模式）**：
   * 当应用通过绿联云网关反代访问时，中间件自动读取 `Ugreen-User-ID`、`Ugreen-User-Name`、`Ugreen-User-Type` 与 `Ugreen-Ttk` 请求头，无需重复登录即可自动创建或关联本地账户并直接进入账本；
   * 支持前端通过 `@ugreen-nas/core` 获取 `third_token`。
2. **独立邮箱账号体系（Standalone / 外网 / 多账号模式）**：
   * **登录**：支持邮箱 + 密码登录，支持「记住我」与持久化令牌；
   * **注册**：支持邮箱验证码注册（`send-code` 60 秒倒计时防刷校验 + 昵称 + 密码 + 随机分配 3D 小猫头像），受管理员后台「允许公开注册」开关控制；
   * **忘记密码 / 重置密码**：通过邮箱验证码完成密码重置（`POST /api/v1/auth/forgot-password`）；
   * **绑定邮箱**：已通过网关免登或未绑定邮箱的用户，可在个人中心随时通过验证码完成邮箱绑定/换绑（`POST /api/v1/user/bind-email`）；
   * **本地开发模式**：无网关头且未携带 Token 时，在开发环境支持本地访客兜底以便联调与测试。

## 四、APP 移动端架构（4 大主 Tab + 6 大手势抽屉/全屏）

移动端专为单手握持与轻盈体验重构，采用**「顶部浮动毛玻璃胶囊 + 底部 4 Tab 胶囊 + 右侧琥珀主操作浮钮（FAB）」**布局，取消传统双层堆叠遮挡。

### 4.1 4 大主 Tab 视图
1. **明细 Tab**：
   * **月度收支概览卡**：展示本月支出、本月收入、净结余；
   * **预算脉搏卡片**：替代传统推广广告位，实时计算并展示「月预算水位进度条」及「今日建议日均可用额度」（剩余预算 / 本月剩余天数）；
   * **成员协作头像条**：快速展示当前账本协作成员头像并一键进入成员管理/邀请；
   * **可收起 AI 记账/问账入口条**：点击一键唤起「AI 聊着记」抽屉，或输入自然语言直达记账；
   * **日期分组流水时间轴**：按日分组卡片展示每日收支合计与每笔明细（双色图标、分类/二级分类、标题商户、支付账户、成员标识与等宽金额），支持左滑/点击进入详情编辑。
2. **收支热力日历 Tab**：
   * **月度收支热力网格**：按周一至周日排列每日单元格，支持**「回今天」**快速锚定；
   * **3 档红陶支出热力 + 收入森绿标识**：低支出 `#FDF0EE`、中支出 `#FADCD6`（`>= ¥150`）、高支出 `#F5C4BC`（`>= ¥500`）；纯收入日使用森绿 `#EAF5EE`，兼有收支日右上角叠加森绿圆点；
   * **今日/选中日流水钻取**：点击任意日期格即时在下方刷新当日收支汇总与流水列表。
3. **统计 Tab**：
   * **周 / 月 / 年周期切换** + **支出 / 收入分析切换**；
   * **✦ 七猫 AI 消费洞察卡**：根据当期真实流水自动提炼消费占比最高项、环比波动与实用节流建议；
   * **呼吸环形图（Breathing Donut）**：带留白分割间隙的分类占比环形图，点击切片交互高亮对应分类金额与百分比；
   * **趋势柱状图**：展示周期内每日/每月收支波动柱状趋势；
   * **分类占比排行 & 单笔排行**：带微圆角进度条的分类明细及当期高额单笔消费榜单。
4. **我的 Tab**：
   * **用户头卡**：展示 3D 小猫头像（点击相机徽标弹出头像库与 Canvas 裁剪器）、用户名、会员徽标、邮箱绑定状态及快捷登录/切换账本按钮；
   * **3 指标统计条**：连续记账天数、累计记录天数、总记账笔数；
   * **财务健康度卡片**：基于储蓄率与预算执行节奏的 0~100 分健康度评估与环形仪表；
   * **6 宫格账务管理**：`资产账户`、`预算管理`、`分类管理`、`定时记账`、`新建账本`、`成员邀请`；
   * **系统设置分组**：`绑定邮箱`、`导入与导出账单`、`切换账号 / 退出登录`。

### 4.2 6 大手势抽屉与全屏交互流
所有底部抽屉均支持手势拖拽控制（支持**紧凑 / 默认 / 全屏**多档位高度吸附与向下轻扫关闭）以及背景锁滚防穿透保护：
1. **双模记账抽屉（AI 聊着记 ⇄ 手动记一笔）**：
   * 支持顶部 Tab 点击切换与面板**水平滑动手势切换**；
   * **AI 聊着记**：支持文本对话记账（如“早饭喝美式咖啡 18.5”）、实时语音波形录制转写、小票拍照/上传 OCR 识别；解析结果以**可内联微调预览确认卡**形式呈现，用户可直接微调金额、分类、账户与日期后一键确认入账；
   * **手动记一笔**：内置加减乘除计算器数字键盘、支出/收入/转账三态切换、一/二级分类网格选择、账户与快捷日期选择、备注与凭证附件，提供「完成」与「再记一笔」连续录入。
2. **账本管理与共享抽屉**：快速切换个人/家庭/旅行/专项账本，查看账本预算、成员数与收支缩影，进入新建或归档管理。
3. **成员与虚拟成员邀请抽屉**：查看当前账本全部成员及角色（所有者/编辑者/访客），生成账本邀请码分享加入、通过邮箱发送协作邀请，或添加无独立账号的**虚拟成员**（如“家人”、“宝宝”、“猫咪”）用于分摊记账归属。
4. **流水详情编辑与预算快捷弹窗**：支持查看与编辑单笔流水全字段、修改/删除流水及凭证附件预览；支持快捷调整本月总预算。
5. **子页面群抽屉**：集中承接「新建账本」、「预算管理（总预算+分类子预算）」、「资产账户管理（余额/信用额度/账单还款日/转账）」、「一/二级分类管理」、「定时记账规则管理」、「绑定邮箱」等完整配置闭环。
6. **全屏认证流 & 3D 头像裁剪弹窗**：覆盖登录 / 注册 / 忘记密码三态切换与验证码倒计时，以及 6 款 3D 小猫选择与 Canvas 圆形裁剪保存流。

| **5** | **资产、预算与定时** | 三栏合一财务规划面板：统一管理现金/银行卡/微信/支付宝/信用卡等账户与净资产、设置月度总预算与分分类子预算、配置与启停周期性定时自动记账规则。 |

| **7** | **多账本与成员邀请** | 创建与管理多个账本（个人/家庭/旅行等）、成员角色权限分配、生成/输入邀请口令加入账本、邮件邀请以及添加账本虚拟成员。 |

### 5.2 轻量管理中台 4 模块（Admin 专属）
仅管理员（`admin`）可见「轻量管理中台」导航分组，提供私有化部署所需的核心运维能力：
1. **宏观指标统计（零隐私账单访问）**：仅聚合展示全站用户数、活跃账本数、累计记账笔数、AI 调用总次数等匿名宏观指标，系统在架构与接口层严格禁止管理员查看任何普通用户的个人流水明细与隐私账单。
2. **AI 配置与 Token 统计**：配置私有或第三方大模型 API Base URL、API Key、模型名称与 OCR 视觉模型，支持一键连通性测试（`POST /api/v1/ai/test`），并按用户维度统计 Token 消耗量与调用趋势。
3. **成员管理与使用限制**：全局控制**「允许公开注册」**开关、全站默认每日 AI 调用限额，以及针对单个用户的独立 AI 日调用上限调整与账号启用/禁用控制。
4. **邮箱与定时备份**：配置系统发信邮箱（SMTP Host / Port / 发件人 / 授权码）并发送测试邮件（`POST /api/v1/admin/smtp-test`）；开启/配置数据库自动热备份开关、备份周期（每天/每周/每月 03:00）与保留份数，支持立即手动生成快照、下载 `.ugledger` / 快照文件及恢复。

### 5.3 PC 弹窗与认证体验
* **居中双模记账弹窗（AI 聊着记 ⇄ 手动记一笔）**：在 PC 任意视图点击「记一笔」或列表行编辑，弹出居中 `580px` 圆角模态框，支持在 AI 自然语言/语音/小票 OCR 解析与手动表单录入之间一键切换。
* **左右分栏全屏认证页**：左侧为暖琥珀品牌视觉、核心能力卖点与 3D 小猫头像展带，右侧提供登录 / 注册 / 忘记密码全套交互与验证码倒计时。

## 六、核心业务引擎（多账本 / 资产 / 分类 / 自动化 / 预算 / 报表）

1. **金融级 Int64 分位精度**：所有交易金额、账户余额、信用额度与预算上限均以整型「分（Cents）」存储与运算，杜绝浮点精度丢失。
2. **原子化账户联动与转账**：支出扣减余额、收入增加余额、跨账户转账（含手续费）在同一数据库事务中原子提交，同步驱动 `daily_summaries` 触发器更新。
3. **两级分类树与正交标签**：预置 14 大支出分类及 4 大收入分类与高频二级分类，支持自定义增删改与排序；支持跨分类正交标签（如“待报销”、“家庭聚餐”）多选标记与过滤。
4. **定时自动记账引擎**：后端调度器按天、工作日、每周、每月、每年自动触发预设规则生成流水，支持随时暂停/启用切换。
5. **高性能统计预聚合**：利用数据库物化汇总表 `daily_summaries` 与覆盖索引，实现毫秒级周/月/年统计、热力日历每日聚合与收支趋势查询。

## 七、本地隐私安全、热快照备份与数据导入导出

1. **100% 本地私有存储**：SQLite 数据库（WAL 模式、`busy_timeout=5000`、`mmap_size=256MB`）、小票凭证图片、自定义头像及备份归档均存放于 `$UGAPP_DATA_DIR`（本地开发回退 `./data`），不经由非授权外部服务器。
2. **在线无锁热快照 (`VACUUM INTO`)**：支持随时手动触发或按周期自动执行热快照，在不锁死正常记账请求的情况下生成完整一致的数据库备份并打包附件。
3. **原子回滚与安全恢复**：执行备份恢复前先进行校验和完整性检查，并自动生成恢复前临时镜像；若恢复中途异常则自动原地回滚，确保零损坏风险。
4. **微信 / 支付宝 CSV 智能导入与导出**：
   * 支持微信支付（UTF-8 BOM）与支付宝（GBK/UTF-8）账单 CSV 解析上传；
   * 自动进行字段映射、四元哈希指纹去重、账户识别与关键词规则预分类，批量预览确认后落盘；
   * 支持全量账本交易流水导出为标准 CSV 文件。

## 八、全量 REST API 接口契约清单（/api/v1）

所有接口均以 `/api/v1` 为前缀，统一返回 `{ "code": 0, "message": "success", "data": ... }` 标准 JSON 信封（文件下载流除外）。

### 8.1 基础健康检查 (Health)
* `GET /api/v1/health` — 服务存活探针与版本号返回（`0.2.0`）。

### 8.2 认证与找回密码 (Auth)
* `POST /api/v1/auth/send-code` — 发送邮箱验证码（注册 / 找回密码 / 绑定邮箱场景，含频控限制）。
* `POST /api/v1/auth/register` — 邮箱验证码注册新账号（自动校验公开注册开关并初始化默认头像与个人账本）。
* `POST /api/v1/auth/login` — 独立账号邮箱密码登录，签发访问令牌。
* `POST /api/v1/auth/forgot-password` — 邮箱验证码校验并重置账号密码。

### 8.3 用户资料与头像 (User)
* `GET /api/v1/user/profile` — 获取当前登录用户信息（含昵称、邮箱绑定状态、角色、头像地址、连续/累计记账统计）。
* `PUT /api/v1/user/profile` — 更新当前用户昵称、预设或裁剪后的自定义头像。
* `POST /api/v1/user/bind-email` — 提交邮箱与验证码完成邮箱绑定或换绑。
* `GET /api/v1/avatars/:filename` — 获取内置 3D 小猫头像或用户自定义上传裁剪后的头像静态资源。

### 8.4 多账本与成员协作 (Books)
* `GET /api/v1/books` — 获取当前用户可见/参与的全部账本列表（含角色、成员数、预算与收支概览）。
* `POST /api/v1/books` — 创建新账本（个人/家庭/旅行/生意/专项，可设定初始预算）。
* `GET /api/v1/books/:id` — 获取单个账本详情与邀请口令信息。
* `PUT /api/v1/books/:id` — 更新账本名称、类型、图标或归档状态。
* `DELETE /api/v1/books/:id` — 安全校验并删除账本（仅 Owner）。
* `GET /api/v1/books/:id/members` — 获取账本协作成员与虚拟成员列表。
* `POST /api/v1/books/:id/members` — 直接添加成员并分配角色（Owner / Editor / Viewer）。
* `PUT /api/v1/books/:id/members/:userId` — 修改成员协作角色或权限。
* `DELETE /api/v1/books/:id/members/:userId` — 移除账本成员。
* `POST /api/v1/books/:id/invite-email` — 向目标邮箱发送账本协作邀请邮件/口令。
* `POST /api/v1/books/:id/virtual-members` — 在账本中创建无独立账号的虚拟记账成员（如家庭成员标签归属）。
* `POST /api/v1/books/join` — 凭账本邀请码加入共享账本。

### 8.5 资产账户管理 (Wallets)
* `GET /api/v1/wallets` — 获取当前账本资产与负债账户列表。
* `POST /api/v1/wallets` — 创建账户（资金/信用/投资/应收应付，含初始余额、额度、账单日、还款日）。
* `PUT /api/v1/wallets/:id` — 更新账户信息、排序或余额校准。
* `DELETE /api/v1/wallets/:id` — 归档或删除账户。
* `GET /api/v1/wallets/summary` — 动态净资产聚合：`{ total_assets, total_liabilities, net_assets }`。

### 8.6 收支分类与标签 (Categories & Tags)
* `GET /api/v1/categories` — 获取当前账本一/二级分类树（支持按支出/收入筛选，含双色图标与颜色 Token）。
* `POST /api/v1/categories` — 新增一级分类或下属二级分类。
* `PUT /api/v1/categories/:id` — 更新分类名称、图标、配色、排序或停用状态。
* `DELETE /api/v1/categories/:id` — 删除自定义分类。
* `GET /api/v1/tags` — 获取当前账本标签列表。
* `POST /api/v1/tags` — 创建自定义正交标签。
* `DELETE /api/v1/tags/:id` — 删除指定标签。

### 8.7 交易流水与附件 (Transactions)
* `GET /api/v1/transactions` — 分页与多维筛选查询流水（时间区间、类型、分类、账户、成员、标签、金额区间、关键词）。
* `POST /api/v1/transactions` — 创建支出、收入或原子转账流水（自动联动账户余额与日预聚合）。
* `GET /api/v1/transactions/:id` — 获取单笔流水详情与关联附件列表。
* `PUT /api/v1/transactions/:id` — 修改交易金额、分类、账户、时间、成员或备注（同步原子重算余额差额）。
* `DELETE /api/v1/transactions/:id` — 删除单笔流水并回滚对应账户余额与汇总统计。
* `POST /api/v1/transactions/batch-delete` — 批量删除多笔选中流水（支持 PC 流水表格批量整理，原子回滚余额）。
* `POST /api/v1/transactions/:id/attachment` — 上传小票/发票凭证图片并关联至指定流水。

### 8.8 预算管理 (Budgets)
* `GET /api/v1/budgets` — 获取当前账本及指定周期的总预算、分分类子预算、实时消耗进度及日均建议可用额度。
* `PUT /api/v1/budgets/total` — 设置或更新账本月度/年度总预算上限及结余滚存选项。
* `PUT /api/v1/budgets/category` — 设置或更新指定一/二级分类的子预算金额。

### 8.9 周期性定时记账 (Recurring)
* `GET /api/v1/recurring` — 获取当前账本全部定时自动记账规则列表。
* `POST /api/v1/recurring` — 创建新的周期性定时记账规则（频率、触发日、金额、分类、账户、备注）。
* `PUT /api/v1/recurring/:id` — 编辑定时记账规则内容。
* `DELETE /api/v1/recurring/:id` — 删除定时记账规则。
* `POST /api/v1/recurring/:id/toggle` — 一键启用或暂停指定定时记账规则。

### 8.10 统计报表与热力日历 (Reports)
* `GET /api/v1/reports/stats` — 综合统计查询（支持周/月/年周期及支出/收入维度，返回分类占比、呼吸环形图切片与单笔排行）。
* `GET /api/v1/reports/monthly` — 基于 `daily_summaries` 的 O(1) 月度收支与分类汇总报表。
* `GET /api/v1/reports/trend` — 周期收支双色对比柱状与净结余走势数据。
* `GET /api/v1/reports/daily` — 按月获取每日汇总收支数据，驱动 APP/PC 收支热力日历与单日钻取。

### 8.11 AI 智能记账、OCR 与财务洞察 (AI)
* `POST /api/v1/ai/chat` — 自然语言/语音转写智能记账与追问省钱建议对话接口，返回结构化待确认流水草案与回复。
* `POST /api/v1/ai/ocr` — 上传购物小票或发票图片进行智能 OCR 解析，提取商家、金额、时间与推荐分类。
* `GET /api/v1/ai/insights` — 基于当前账本近期真实流水生成 AI 消费洞察与财务诊断建议卡片。
* `POST /api/v1/ai/test` — 测试当前系统或指定 AI 模型配置 API 连通性（返回延迟与状态）。

### 8.12 轻量管理中台 (Admin，需管理员权限)
* `GET /api/v1/admin/overview` — 宏观指标聚合概览（注册用户数、账本数、总流水笔数、AI 调用趋势，严格零个人账单隐私泄露）。
* `GET /api/v1/admin/ai-config` — 读取全局 AI 接口配置（API URL、模型名称、OCR 模型、脱敏 Key 状态）。
* `PUT /api/v1/admin/ai-config` — 更新全局 AI 服务商与模型配置。
* `GET /api/v1/admin/ai-usage` — 查询分用户 AI Token 消耗与调用次数统计列表。
* `GET /api/v1/admin/reg-config` — 获取公开注册开关与默认每日 AI 调用限额配置。
* `PUT /api/v1/admin/reg-config` — 更新公开注册开关与默认每日 AI 调用限额。
* `GET /api/v1/admin/users` — 获取系统用户列表（昵称、脱敏邮箱、角色、记账笔数、日调用限额、启用状态，不含账单详情）。
* `PUT /api/v1/admin/users/:id` — 修改指定用户的每日 AI 调用限额或启停状态。
* `GET /api/v1/admin/system-config` — 获取系统 SMTP 发信配置与数据库定时备份策略配置。
* `PUT /api/v1/admin/system-config` — 更新 SMTP 发信配置与定时备份开关/周期/保留份数。
* `POST /api/v1/admin/smtp-test` — 触发发送测试邮件以验证 SMTP 参数有效性。

### 8.13 账单导入导出与热快照 (Import/Export & Snapshots)
* `GET /api/v1/export` — 导出当前账本流水为标准 CSV 文件。
* `POST /api/v1/imports/wechat` — 上传并智能解析微信支付 CSV 账单（去重与规则预分类）。
* `POST /api/v1/imports/alipay` — 上传并智能解析支付宝 CSV 账单（去重与规则预分类）。
* `POST /api/v1/imports/commit` — 将确认后的解析账单批量落盘写入账本并联动账户余额。
* `GET /api/v1/snapshots` — 列出已有在线热快照备份文件列表。
* `POST /api/v1/snapshots/create` — 触发 `VACUUM INTO` 生成在线无锁热快照（`.ugledger` / `.db` 打包）。
* `POST /api/v1/snapshots/restore` — 上传或指定快照执行完整性校验、恢复前镜像与原子回滚安全还原。
* `GET /api/v1/snapshots/:id/download` — 下载指定历史备份快照文件。
* `DELETE /api/v1/snapshots/:id` — 删除指定的旧快照文件。
